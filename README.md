# EcoEvo Job Searcher

A job board for ecology and evolution positions, combining listings from **[ecoevojobs](https://ecoevojobs.net/)**, **[EvolDir](https://www.evoldir.net/brian/Jobs.html)**, and **[Science Careers](https://jobs.sciencecareers.org/jobs/)**.

**https://calcharp.github.io/EcoEvoJobSearcher/**

Filter by phrase, source, map area, and dates; sort and export results; subscribe to RSS for new or all open jobs. Listings refresh automatically every few hours.
